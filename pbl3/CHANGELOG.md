# PBL3 공통 데이터 변경 기록

## v1 — 2026-11-23

- 미션2 `public` 테이블은 수정하지 않고 `pbl3` 스키마에 4개 테이블 추가.
- 기존 가상 프로그램 10개를 각 5회차(총 50회차)로 확장.
- 미션2 학생 32명을 기반으로 회차별 신청 및 출석 상태 생성.
- 학과·학년별 대표 시간표와 학기별 가상 시험기간 추가.
- 수업 충돌/시험기간에 따른 신청·출석 확률 감소를 합성 데이터 규칙에 반영.
- 기존 완료 설문 및 승인된 프로그램 마일리지 신청이 있는 학생은 해당 프로그램의 본행사 출석과 연결.
- 영효 파트 프로그램 연결 승인 지출/고유 출석/만족 응답자별 단가 조회 추가.

### 기존 파일 변경 여부

**없음.** `reset.sql`, `schema/`, `seed/`, `queries/`, `demo/`에 변경을 가하지 않음.

### 제한사항

- 가상 데이터 50회차/32명은 기계학습 성능을 일반화하기에 충분한 표본이 아니다.
- 만족도 점수의 무성의 응답 판정이나 후속 참여 예측은 별도 구현이 필요하다.
- 출석과 만족도에 중복이 없도록 프로그램별/학생별 단위에서 집계한 뒤 결합해야 한다.
- 프로그램 외 공통 지출은 배분 기준이 없어 프로그램 총비용에 포함하지 않는다.
