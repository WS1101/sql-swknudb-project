# 마일리지 설계 보완

- `mileage_application.registration_path`는 `VARCHAR(20)`으로 정의하고, 설계서의 `STUDENT_REQUEST` / `ADMIN_DIRECT` 값을 사용한다. 학생 직접 신청 시 `registered_by = student_no` 제약을 적용한다.
- `program`은 만족도 조사만 진행하는 경우를 포함한 모든 SW중심대학사업 프로그램을 나타낸다. 마일리지 부여 여부는 해당 프로그램의 `mileage_criteria` 존재 여부로 구분한다.
- `ix_mileage_application_status`는 승인대기 목록(Q07) 조회를 위해 `status = 'PENDING'`인 신청만 포함하는 부분 인덱스로 정의한다.
