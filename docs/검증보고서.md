# 검증 보고서

- DBMS: PostgreSQL (버전: TODO)
- 기준 데이터: `reset.sql` 실행 직후 (스키마 + seed)
- 예상값 산출: seed 생성 규칙(학번 순번, 점수식, 상태 배정 규칙, 금액 비율)을 그대로 따라 계산.
  seed README의 기준값(마일리지 신청 84건·승인 합계 2,475점, 지출 42건·승인 106,750,000원,
  만족도 응답 132건·상세 522건)과 일치하는 것을 확인한 뒤 각 쿼리 예상값을 구했다.
- 실제값: 쿼리·테스트 실행 결과를 옮겨 적고 일치 여부를 표시한다. 실행 화면은 `docs/screenshots/`.

> 요청ID·신청ID 같은 자동증가 번호는 reset 직후 기준이다. 테스트를 실행하면 ROLLBACK을 해도
> 시퀀스는 증가하므로, ID를 비교할 때는 reset 후 쿼리를 먼저 실행한다.
