# 우진이 공통 참여 데이터와 Survey Insight 연결 계약

이 문서는 테이블 설계 지시가 아니라 **분석에 필요한 출력 형식**이다. 우진이가 `program_session`, `program_participant`, `course_timetable`을 어떻게 구성하든 연결 VIEW의 출력 형식만 맞추면 설문 분석은 유지된다.

## 먼저 합의할 네 가지

1. 학생과 프로그램을 기존 `student.student_no`, `program.program_id`로 연결할 수 있는가?
2. 신청/승인/취소와 실제 출석 상태를 어느 컬럼에서 구분하는가?
3. 회차별 실제 출석 시각을 얻을 수 있는가? 날짜만으로 임의 시각을 만들지 않는다.
4. 1회 출석과 전체 이수를 어떻게 구분하는가? 현재 재참여 정의는 다른 프로그램에 실제 출석한 사건이다.

`course_timetable`은 우진이의 참여 저조 원인/시간 충돌 분석에 활용할 수 있다. 설문 품질 기본판에는 의존성을 추가하지 않는다.

## 출석 연결 VIEW

`analytics.v_attendance_event`는 **실제 출석 이벤트 1건당 1행**이다.

| 컬럼 | PostgreSQL 타입 | 의미 |
|---|---|---|
| student_no | VARCHAR(20) | 실제 출석 학생 |
| program_id | INT | 회차가 소속된 프로그램 |
| attended_at | TIMESTAMPTZ | 실제 출석 시각 |

신청/마일리지 승인만으로 출석 행을 만들지 않는다. 시각 미측정은 임의로 채우지 말고 확정 출석 집계에서 보류한다. 여러 회차는 여러 행을 유지한다. 최초 출석으로만 합치면 설문 이후의 회차를 놓칠 수 있다. 참여자 수는 `count(DISTINCT student_no)`, 재참여 여부는 EXISTS로 중복을 방지한다.

`schema/11_survey_participation_link.sql` 상단 DO 블록은 VIEW가 없을 때만 빈 구조를 만든다. 테이블이 정해지면 **이 VIEW를 만드는 SELECT만** 실제 JOIN으로 작성해 `CREATE OR REPLACE VIEW`로 적용한다. 미확정 컬럼명을 추정한 실행 SQL은 넣지 않았다.

```sql
SELECT * FROM analytics.v_attendance_event LIMIT 20;
SELECT program_id,count(*) AS events,count(DISTINCT student_no) AS students
FROM analytics.v_attendance_event GROUP BY program_id;
-- 실제 매핑과 출석 의미를 확인한 뒤
UPDATE analytics.survey_participation_setting
SET attendance_connected=TRUE WHERE setting_id=1;
```

## 재참여율에 필요한 추가 확인

출석이 없다는 것과 참여 기회가 없었다는 것은 다르다. 출석만 연결된 단계는 **참여 기회 연계 대기**로 두며 재참여율을 계산하지 않는다. 출석한 학생만 분모에 남아 100%처럼 보이는 문제를 방지한다.

학생에게 실제 제공된 기회가 있다면 `analytics.v_program_opportunity`를 연결한다.

| 컬럼 | 타입 | 의미 |
|---|---|---|
| student_no | VARCHAR(20) | 기회를 제공받은 학생 |
| program_id | INT | 후속 프로그램 |
| offered_at | TIMESTAMPTZ | 제공 시각 |
| scheduled_at | TIMESTAMPTZ | 해당 기회의 예정 시각 |

모든 학생과 프로그램을 CROSS JOIN해 기회를 가정하지 않는다. 대상 학과·신청 자격·공급·시간표 등 확인 가능한 범위를 합의한다. 제공 시각은 예정 시각 이하여야 한다.

출석과 기회가 실제로 수집된 범위는 `analytics.participation_coverage`에 출처별로 기록한다. `existing`은 기존 DB, `synthetic`은 분리된 시연 프로그램이다. 실제 확인한 시작/종료와 근거를 입력하고 `opportunity_connected=TRUE`로 설정한다.

제출 시점부터 90일을 관찰할 수 있고 실제 후속 기회가 확인되는 경우만 재참여율 분모에 포함한다. 설문 제출 **이후**, 90일 이내(경계 포함), **다른 프로그램**의 출석을 재참여로 인정한다. 수집 범위 불명·관찰 부족·기회 없음은 NULL이다.
